Tags comme Resources

Encoder la hiérarchie Macro → Mécanique → Spécifique dans des .tres Godot, rendre chaque tag interactif dans les blocs de texte (hover & clic), et résoudre les correspondances avec descendance transitive en O(1).

Tags Resource RichTextLabel Tooltip TagRegistry

Vue d'ensemble

Le système de tags suit une hiérarchie à trois niveaux : Macro (racines larges comme #degat_direct, #controle), Mécanique (sous-familles comme #dot, #slow) et Spécifique (feuilles comme #poison, #armure). Chaque tag est une TagData Resource (.tres) stockée dans res://resources/tags/.

L'autoload TagRegistry charge ces Resources au démarrage, construit un cache de descendants transitifs, et expose matches_tag() / element_matches() utilisés partout dans le jeu (RelicManager, SkillManager, LootManager…). Dans les descriptions BBCode, chaque tag devient un [url=tag:#dot]…[/url] : le RichTextLabel émet meta_hover_started / meta_clicked qui alimentent le TooltipManager.

Principe clé : une relique ciblant #controle affecte automatiquement tous les éléments portant #stun, #slow, #deplacement, #pousser, etc. — une seule fois par élément, même s'il porte plusieurs tags enfants. La hiérarchie est dans les .tres, pas dans une constante GDScript.

Chaîne de données

📄
TagData (.tres)

Une Resource par tag : tag_id, label, color, icon, niveau, description, parent_tag, children[]. Configuré entièrement depuis l'Inspecteur Godot.

⚙️
TagRegistry (Autoload)

Charge tous les .tres de res://resources/tags/ au démarrage. Construit le cache de descendants une seule fois. Expose matches_tag(), element_matches(), get_tag().

💬
RichTextLabel + Tooltip

Le BBCode baked embarque [url=tag:#dot]…[/url]. meta_hover_started → TooltipManager.show_tag() → panneau avec icône, niveau, description et pilules enfants cliquables.

TagData — la Resource

Chemin : res://resources/tags/tag_data.gd. Un fichier .tres par tag, nommés tag_dot.tres, tag_controle.tres, etc. Les relations children se remplissent par glisser-déposer dans l'Inspecteur.

GDScript — tag_data.gd 
# tag_data.gd
# Chemin : res://resources/tags/tag_data.gd
class_name TagData
extends Resource

## Identifiant canonique du tag, ex : "#dot", "#controle"
@export var tag_id: String = ""

## Nom affiché dans le tooltip, ex : "Dégâts sur la Durée"
@export var label: String = ""

## Couleur du mot-clé dans les RichTextLabel
@export var color: Color = Color(0.4, 0.85, 0.5)

## Icône optionnelle affichée dans le tooltip (texture 32×32)
@export var icon: Texture2D = null

## Niveau hiérarchique — pour l'affichage dans le tooltip
@export_enum("Macro", "Mécanique", "Spécifique") var niveau: int = 1

## Description complète affichée dans le tooltip
@export_multiline var description: String = ""

## Tag parent direct (null si Macro/racine)
@export var parent_tag: TagData = null

## Enfants directs — glisser-déposer depuis l'Inspecteur
@export var children: Array[TagData] = []

TagRegistry — Autoload

Charge tous les .tres du dossier au démarrage, construit le cache de descendants par récursion (une seule fois), puis répond en O(1) à chaque matches_tag().

GDScript — tag_registry.gd 
# tag_registry.gd  — Autoload : TagRegistry
# Chemin : res://systems/tags/tag_registry.gd
extends Node

var _registry: Dictionary = {}
var _descendants_cache: Dictionary = {}

const TAGS_DIR := "res://resources/tags/"


func _ready() -> void:
    _load_all_tags()
    _build_descendants_cache()


# ── Chargement ──────────────────────────────────────────────────────────────

func _load_all_tags() -> void:
    var dir := DirAccess.open(TAGS_DIR)
    if dir == null:
        push_error("TagRegistry: dossier introuvable → " + TAGS_DIR)
        return
    dir.list_dir_begin()
    var fname := dir.get_next()
    while fname != "":
        if fname.ends_with(".tres"):
            var res := load(TAGS_DIR + fname)
            if res is TagData and res.tag_id != "":
                _registry[res.tag_id] = res
        fname = dir.get_next()
    dir.list_dir_end()


# ── API publique ─────────────────────────────────────────────────────────────

## Récupère une TagData par son identifiant canonique.
func get_tag(tag_id: String) -> TagData:
    return _registry.get(tag_id, null)

## true si candidate_tag est query_tag ou l'un de ses descendants.
func matches_tag(query_tag: String, candidate_tag: String) -> bool:
    if query_tag == candidate_tag:
        return true
    return candidate_tag in _get_descendants(query_tag)

## true si au moins un tag de element_tags matche query_tag.
## Garantit qu'un élément ne reçoit le bonus qu'une seule fois.
func element_matches(query_tag: String, element_tags: Array[String]) -> bool:
    for tag in element_tags:
        if matches_tag(query_tag, tag):
            return true
    return false

## true si tag_a est un ancêtre de tag_b.
func is_ancestor_of(tag_a: String, tag_b: String) -> bool:
    return tag_b in _get_descendants(tag_a)


# ── Cache descendants (transitif) ───────────────────────────────────────────

func _build_descendants_cache() -> void:
    for tag_id in _registry:
        if not _descendants_cache.has(tag_id):
            _collect_descendants(tag_id)

func _get_descendants(tag_id: String) -> Dictionary:
    return _descendants_cache.get(tag_id, {})

func _collect_descendants(tag_id: String) -> Dictionary:
    if _descendants_cache.has(tag_id):
        return _descendants_cache[tag_id]

    var result: Dictionary = {}
    var tag_data: TagData = _registry.get(tag_id, null)
    if tag_data == null:
        _descendants_cache[tag_id] = result
        return result

    for child in tag_data.children:
        if child == null or child.tag_id == "":
            continue
        result[child.tag_id] = true
        var sub := _collect_descendants(child.tag_id)
        for sub_id in sub:
            result[sub_id] = true

    _descendants_cache[tag_id] = result
    return result
Sens unique intentionnel : matches_tag("#dot", "#poison") → true (poison est sous dot). matches_tag("#poison", "#dot") → false. Une relique ciblant #dot affecte tout le sous-arbre ; une relique ciblant #poison reste spécifique.

Tags interactifs dans les descriptions

Le DescriptionParser (baking @tool) enrobe chaque mention de tag dans un [url=tag:#id]…[/url]. Le RichTextLabel émet alors meta_hover_started et meta_clicked que card_display.gd route vers le TooltipManager.

GDScript — description_parser.gd (extrait) 
## Emballe un tag_id en BBCode interactif coloré.
static func _wrap_tag(tag_id: String) -> String:
    var tag_data: TagData = TagRegistry.get_tag(tag_id)
    if tag_data == null:
        return tag_id  # fallback texte brut

    var hex := "#%02x%02x%02x" % [
        int(tag_data.color.r * 255),
        int(tag_data.color.g * 255),
        int(tag_data.color.b * 255),
    ]
    # [url] = meta-link — RichTextLabel émet meta_hover_started/meta_clicked
    return "[url=tag:%s][color=%s]%s[/color][/url]" % [
        tag_id, hex, tag_data.label
    ]

# Résultat dans le BBCode baked :
# Inflige [url=tag:#dot][color=#66D96A]Dégâts sur la Durée[/color][/url]
# de type [url=tag:#poison][color=#A3E635]Poison[/color][/url].

func setup(effect_data: EffectData, stat_mods: Dictionary = {}) -> void:
    _effect_data = effect_data
    _stat_mods   = stat_mods
    _refresh()
    # Hover souris → tooltip flottant

    label.meta_hover_ended.connect(func(_m): TooltipManager.hide())

func _on_meta_hover(meta: Variant) -> void:
    var s := str(meta)
    if s.begins_with("tag:"):
        TooltipManager.show_tag(s.substr(4), get_global_mouse_position())

func _on_meta_clicked(meta: Variant) -> void:
    var s := str(meta)
    if s.begins_with("tag:"):
        TooltipManager.show_tag(s.substr(4), get_global_mouse_position())

# ── Navigation manette (L1 / R1) ─────────────────────────────────────────────
func _gui_input(event: InputEvent) -> void:
    if not _keywords.is_empty():
        if event.is_action_pressed("ui_focus_prev"):
            _cycle_keyword(-1)
        elif event.is_action_pressed("ui_focus_next"):
            _cycle_keyword(1)

func _cycle_keyword(dir: int) -> void:
    _focused_keyword_index = wrapi(
        _focused_keyword_index + dir, 0, _keywords.size()
    )
    var tag_id := _keywords[_focused_keyword_index]
    TooltipManager.show_tag(tag_id, global_position + size / 2.0)

TooltipManager & tooltip_panel

Le TooltipManager est un autoload CanvasLayer (layer 128) qui instancie un seul tooltip_panel.tscn et le repositionne intelligemment pour éviter les débordements d'écran. Le panel affiche : icône, nom coloré, niveau hiérarchique, description, et une rangée de pilules cliquables pour les tags enfants directs.

GDScript — tooltip_manager.gd 
# tooltip_manager.gd  — Autoload : TooltipManager
extends CanvasLayer

var _panel: Control
const PANEL_SCENE  := preload("res://ui/tooltip_panel.tscn")
const SCREEN_MARGIN := 12.0

func _ready() -> void:
    _panel = PANEL_SCENE.instantiate()
    add_child(_panel)
    _panel.visible = false
    layer = 128   # au-dessus de tout le reste

func show_tag(tag_id: String, screen_pos: Vector2) -> void:
    var tag_data: TagData = TagRegistry.get_tag(tag_id)
    if tag_data == null:
        return
    _panel.setup(tag_data)
    _panel.visible = true
    _reposition(screen_pos)

func hide() -> void:
    _panel.visible = false

func _reposition(pos: Vector2) -> void:
    var vp   := get_viewport().get_visible_rect().size
    var size := _panel.size
    var x    := minf(pos.x + 14.0, vp.x - size.x - SCREEN_MARGIN)
    var y    := minf(pos.y + 14.0, vp.y - size.y - SCREEN_MARGIN)
    _panel.global_position = Vector2(x, y)
GDScript — tooltip_panel.gd 
# tooltip_panel.gd
extends PanelContainer

@onready var icon_rect:          TextureRect    = $VBox/HBox/Icon
@onready var label_text:         Label          = $VBox/HBox/Label
@onready var niveau_text:        Label          = $VBox/Niveau
@onready var desc_label:         RichTextLabel  = $VBox/Description
@onready var children_container: HBoxContainer  = $VBox/Children

func setup(tag_data: TagData) -> void:
    # Icône
    icon_rect.texture = tag_data.icon
    icon_rect.visible = tag_data.icon != null

    # Nom coloré
    label_text.text = tag_data.label
    label_text.add_theme_color_override("font_color", tag_data.color)

    # Niveau hiérarchique
    const NIVEAUX := ["Macro", "Mécanique", "Spécifique"]
    niveau_text.text = NIVEAUX[tag_data.niveau]

    # Description (peut elle-même contenir du BBCode)
    desc_label.bbcode_enabled = true
    desc_label.text = tag_data.description

    # Pilules enfants cliquables
    for child in children_container.get_children():
        child.queue_free()
    for child_tag in tag_data.children:
        if child_tag == null: continue
        children_container.add_child(_make_pill(child_tag))

func _make_pill(tag_data: TagData) -> Button:
    var btn := Button.new()
    btn.text = tag_data.label
    btn.add_theme_color_override("font_color", tag_data.color)
    btn.pressed.connect(func():
        TooltipManager.show_tag(tag_data.tag_id, get_global_mouse_position())
    )
    return btn

Utilisation dans les systèmes existants

RelicManager — bonus passif hiérarchique

L'anti-doublon est garanti par un dictionnaire local : un élément reçoit le bonus une seule fois même s'il porte plusieurs tags enfants du tag ciblé.

GDScript — relic_manager.gd (extrait) 
func apply_relic_bonus_to_build(relic_data: RelicData) -> void:
    var query_tag: String  = relic_data.target_tag
    var already_applied_to: Dictionary = {}   # anti-doublon par élément

    for slot in BuildManager.get_all_slots():
        var element = slot.effect_data
        if element == null: continue

        var element_id: String = element.resource_path
        if already_applied_to.has(element_id): continue

        # Test hiérarchique — matche si element porte un tag descendant de query_tag
        if TagRegistry.element_matches(query_tag, element.tags):
            _apply_bonus(element, relic_data)
            already_applied_to[element_id] = true

SkillManager — CheckBuildTag hiérarchique

GDScript — skill_manager.gd (extrait) 
## Vérifie si le build contient au moins un élément dont le tag
## est query_tag ou l'un de ses descendants.
func has_skill_matching_tag(query_tag: String) -> bool:
    for slot in BuildManager.get_all_slots():
        var element = slot.get_active_element()
        if element and TagRegistry.element_matches(query_tag, element.tags):
            return true
    return false
