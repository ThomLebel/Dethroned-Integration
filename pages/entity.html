Interface entité

Contrat de méthodes partagé par toutes les entités mobiles. Les managers appellent ces méthodes sans connaître le type exact de l'entité.

BilleJoueur EnemyBase BossBase Invocations
Ce n'est pas une classe abstraite GDScript. C'est une convention de signatures. Chaque entité implémente les méthodes dans son propre script, en déléguant à ses composants internes.

Groupe A — Identité & Position

Ces cinq méthodes ne doivent jamais échouer. Appelées en permanence par SpatialHash, TriggerConditions, et tous les managers.

GDScript — Groupe A dans enemy_base.gd
func get_entity_id() -> String:
    return data.id + "_" + str(get_instance_id())

func get_entity_type() -> String:
    return "enemy"

func get_tags() -> Array[String]:
    return data.tags + status_component.get_active_tags()

func get_position() -> Vector3:
    return global_position

func get_velocity() -> Vector3:
    return velocity

Groupe B — Combat & État

Principe clé : chaque entité applique ses immunités et résistances localement dans receive_damage(). Les managers ne connaissent pas ces règles internes.
MéthodeUsage
get_hp_ratio() → floatPV actuels / PV max. Lu intensivement par TriggerConditions.
receive_damage(amount, tags, source)Point d'entrée unique. L'entité filtre localement avant HealthComponent.
receive_heal(amount)Soin, plafonné à max_hp.
is_dead() → boolDélègue à HealthComponent.is_dead()
receive_status(id, duration, value)L'entité peut refuser si immunité active.
has_status(id) → boolLu par TriggerConditions.
receive_impulse(direction, force)Knockback, dash forcé. force=0 = root.
get_mass() → floatCalcul ACC et knockback.
get_defense_coeff() → floatcoeff_DEF effectif, appliqué en C2 par CombatManager.

Règle du knockback conditionnel

Le knockback physique C1 est supprimé si C3 a posé ctx["knockback_applied"] = true ou ctx["root_applied"] = true. Les EffectBehaviour qui appliquent un mouvement posent ce flag — évite le double mouvement incohérent.
GDScript — receive_damage avec résistances locales
# Dans enemy_base.gd — les résistances sont locales
func receive_damage(amount: float, source_tags: Array[String], source: Node) -> void:
    var effective := amount
    if _is_frontal_hit(source) and data.damage_reduction_front > 0.0:
        effective *= (1.0 - data.damage_reduction_front)
    if "dot" in source_tags and status_component.has_status("chi_actif"):
        return  # immunité locale — HealthManager ne le sait pas
    effective *= (1.0 - data.damage_reduction_global)
    health_component.apply_damage(effective)

Groupe C — Physique & Mouvement

apply_resolved_velocity() est appelée uniquement par PhysicsManager. Il accumule toutes les résolutions de la frame avant d'écrire les vélocités.
MéthodeUsage
get_collision_radius() → floatCollisionResolver — détection et résolution d'interpénétration
get_bounce_coefficient() → floatAprès velocity.bounce(normal)
get_friction() → floatMultiplicateur vélocité/frame
apply_resolved_velocity(v)PhysicsManager uniquement — jamais les entités elles-mêmes
get_steering_factor() → floatBulletTimeManager — retourne 0.0 pour ennemis et invocations
