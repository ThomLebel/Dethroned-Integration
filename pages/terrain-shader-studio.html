🌍 Terrain Shader Studio

Outil de prévisualisation WebGL GPU pour les textures de sol des biomes — sol principal + îlots secondaires procéduraux, style cartoon posterisé.

WebGL GPU Environnements WFC / Biomes Outil interactif
Mode d'emploi
Utilisez les onglets Layout, Biomes, Variation et Shader pour paramétrer l'apparence du sol. Le rendu est calculé en temps réel sur GPU (WebGL). Cliquez 🔀 Regénérer pour changer la seed procédurale. Les 4 modes de vue (Rendu final / Sol principal / Îlots seuls / Poids biomes) permettent d'inspecter chaque couche indépendamment.
