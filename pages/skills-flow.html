Flux d'un événement de jeu

De la collision physique à l'exécution d'un effet — comment l'information circule entre CombatManager, SkillManager, TriggerRunner et EffectRunner dans l'architecture Manager Graph.

Résumé : CombatManager construit le ctx brut et l'enrichit. SkillManager coordonne TriggerRunner et EffectRunner. Le ctx circule sans jamais déclencher de get_node(). VFX et Audio sont notifiés après le pipeline, jamais pendant.

Flux complet — collision joueur → ennemi

Séquence d'appels — appels directs uniquement
# 1. PhysicsManager détecte la collision (CollisionResolver)
PhysicsManager.on_collision(bille, ennemi)

# 2. CombatManager résout la séquence C1→C5
CombatManager.resolve_hit(bille, ennemi)
  # C1 : ACC calculé et infligé
  # C2 : défenses passives appliquées
  # C3 → appel direct SkillManager
  SkillManager.process_event("enemy_hit", ctx)
    # TriggerRunner évalue les déclencheurs du build
    # Pour chaque déclencheur satisfait : EffectRunner.execute()
    # Pipeline ctx circule de behaviour en behaviour
    # Après le pipeline : VFXManager + AudioManager notifiés
  # C4 : compétences de réaction de l'ennemi
  # C5 : effets persistants (DoT, zones)

# 3. Signaux EventBus résiduels (Couche 4 uniquement)
EventBus.enemy_hit.emit(ctx)   # → AudioManager, RunMetricsCollector

Le dictionnaire ctx — Blackboard complet

Le ctx est enrichi couche par couche. CombatManager fournit les données physiques. SkillManager.ContextBuilder ajoute les données de build et injecte les managers. Les behaviours lisent et écrivent sans jamais appeler get_node().

Règle des compétences avancées — tag matching

Compatibilité Avancés : un Déclencheur Avancé n'est proposé au joueur que si son build contient déjà au moins un tag compatible. CheckBuildTag est systématiquement la dernière condition de tout TriggerData de type "advanced".
GDScript — vérification dans ContextBuilder
# Lors de la construction du ctx, ContextBuilder expose les tags du build
func _enrich_build_tags(ctx: Dictionary) -> void:
    var tags: Array[String] = []
    for slot in BuildManager.get_active_slots():
        tags.append_array(slot.trigger_data.tags)
        tags.append_array(slot.effect_data.tags)
    # CheckBuildTag lit ctx["build_tags"] pour valider la compatibilité
    ctx["build_tags"] = tags
