Ordre de déclaration des Autoloads

Dans Godot : Project → Project Settings → Autoload. L'ordre détermine l'initialisation — déclarer dans l'ordre des couches, les plus basses en premier.

Ordre recommandé
# 1. Infrastructure (aucune dépendance)
Registry          → res://autoloads/infrastructure/registry.gd
PoolManager       → res://autoloads/infrastructure/pool_manager.gd

# 2. Couche 2 — État (avant C1 qui en a besoin)
HealthManager     → res://autoloads/managers/health_manager.gd
StatusManager     → res://autoloads/managers/status_manager.gd
BuildManager      → res://autoloads/managers/build_manager.gd
ResourceManager   → res://autoloads/managers/resource_manager.gd
DifficultyManager → res://autoloads/managers/difficulty_manager.gd

# 3. Couche 1 — Combat (peut appeler C2)
PhysicsManager    → res://autoloads/managers/physics_manager.gd
SkillManager      → res://autoloads/managers/skill_manager.gd
CombatManager     → res://autoloads/managers/combat_manager.gd
EnemyManager      → res://autoloads/managers/enemy_manager.gd
BulletTimeManager → res://autoloads/managers/bullet_time_manager.gd

# 4. Couche 0 — Orchestration
RunManager        → res://autoloads/managers/run_manager.gd

Template d'un manager

GDScript — template_manager.gd
# À copier pour chaque nouveau manager
extends Node

# ── État interne (privé) ──────────────────────────────
var _data: Dictionary = {}

# ── Initialisation ────────────────────────────────────
func _ready() -> void:
    _init_subsystems()

func _init_subsystems() -> void:
    pass  # initialiser les sous-systèmes ici

# ── Interface publique ────────────────────────────────
# Les autres managers n'appellent que ces méthodes
func do_something(entity: Node, value: float) -> void:
    _internal_logic(entity, value)

# ── Logique interne (privée — préfixée _) ─────────────
func _internal_logic(entity: Node, value: float) -> void:
    pass

# ── Debug ─────────────────────────────────────────────
func debug_state() -> String:
    return ""

Démarrage en local

Important : le site utilise fetch() — il ne fonctionne pas en ouvrant index.html directement. Utiliser un serveur HTTP local.
Terminal — serveur local
# Option 1 — Python (recommandé)
python3 -m http.server 8080
# → http://localhost:8080

# Option 2 — Node.js
npx serve .

# Option 3 — VS Code
# Extension "Live Server" → clic droit index.html → Open with Live Server
