Pourquoi Manager Graph ?

Analyse comparative EventBus vs Manager Graph sur 5 critères. Ce document justifie le choix architectural retenu pour Dethroned.

Le problème de l'EventBus pur

L'EventBus natif Godot est élégant pour des projets simples. Sur un jeu avec 15+ systèmes, 100+ événements et un système de compétences modulaire, il devient un obstacle à la lisibilité.

Symptôme concret : débugger un comportement inattendu nécessite de grepper tout le projet. La callstack s'arrête à l'émission du signal.
  • L'ordre de résolution est implicite et fragile
  • Retirer un émetteur est silencieux — les écouteurs orphelins ne se plaignent pas
  • Les performances se dégradent avec le broadcast aveugle à grande échelle
  • Impossible de mocker un signal pour les tests unitaires
