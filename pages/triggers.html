Déclencheurs

~114 déclencheurs assemblés depuis ~20 blocs TriggerCondition. Chaque déclencheur est une TriggerData.tres — aucun code par déclencheur.

Principe : un déclencheur ne va jamais chercher l'information lui-même. Tout lui arrive dans le ctx. Les conditions lisent ctx, elles ne font pas de get_node().

Structure d'un déclencheur

GDScript — TriggerData (Resource)
extends Resource
class_name TriggerData

@export var id: String = ""
@export var event_ids: Array[String] = []   # ex: ["enemy_hit"]
@export var loc_type: String = "loc_soi"     # loc_cible / loc_point / loc_soi / loc_global
@export var cooldown: float = 0.3
@export var tags: Array[String] = []
@export var conditions: Array[TriggerCondition] = []

# Paramètres partagés entre les conditions
@export var threshold_value: float = 0.0
@export var threshold_count: int = 0
@export var time_window: float = 0.0
@export var required_tag: String = ""

Exemples de déclencheurs assemblés

Collision Standard (0 condition)

TriggerData.tres — DB-COL-01
TriggerData {
    id: "DB-COL-01"  event_ids: ["enemy_hit"]
    loc_type: "loc_cible"  cooldown: 0.3
    conditions: []  # tout signal enemy_hit passe
}

Enchaînement Rapide (3 conditions)

TriggerData.tres — DB-COL-12
TriggerData {
    id: "DB-COL-12"  event_ids: ["enemy_hit"]
    loc_type: "loc_cible"  time_window: 0.5
    conditions: [
        CheckTargetDifference {},             # cible différente de la précédente
        CheckTimeSince {                       # last hit il y a moins de 0.5s
            event_key: "last_enemy_hit",
            time_window: 0.5
        },
        RecordTimestamp {                      # met à jour (toujours vrai)
            event_key: "last_enemy_hit"
        }
    ]
}

Compteur de Rebonds (2 conditions + état)

TriggerData.tres — DB-REB-05
TriggerData {
    id: "DB-REB-05"  event_ids: ["wall_hit"]
    loc_type: "loc_soi"  threshold_count: 4
    conditions: [
        IncrementTriggerCounter {             # incrémente (toujours vrai)
            counter_key: "wall_bounce_count",
            reset_on_room: true
        },
        CheckCounter {                         # déclenche au 4e rebond
            counter_key: "wall_bounce_count",
            threshold_count: 4
        }
    ]
}
