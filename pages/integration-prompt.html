Prompt d'intégration

Prompt à donner à Claude pour adapter n'importe quel contenu existant — outil interactif, visualiseur, documentation — en une nouvelle page autonome du site.

Architecture du site — Le site est multi-fichiers. index.html est le shell global (CSS, navigation, moteur). gamedata.js expose les données du jeu globalement (effets, triggers, faveurs, reliques…). Chaque page est un fragment HTML dans pages/ID.html, chargé à la demande. Les <script> et les <style> dans les fragments fonctionnent normalement — aucune modification de index.html n'est nécessaire pour ajouter une page.

════════════════════════════════════════
ARCHITECTURE DU SITE
════════════════════════════════════════

Structure de fichiers :
  index.html       ← Shell (CSS global, navigation, JS core) — NE PAS MODIFIER
  nav.json         ← Arbre de navigation — seule modification nécessaire
  gamedata.js      ← Données du jeu (chargé globalement par index.html) — NE PAS MODIFIER
  pages/ID.html    ← Fragments de page — à créer

Chaque page est un fragment HTML sans <html>/<head>/<body>,
injecté dynamiquement dans #page-container.

Après injection, index.html appelle automatiquement :
  - runPageScripts()   → réexécute tous les <script> du fragment
  - applyPageLayout()  → active la pleine largeur si data-fullwidth="true"

CONSÉQUENCE : les pages sont 100% autonomes. Aucune modification
de index.html n'est jamais nécessaire pour ajouter une nouvelle page.

════════════════════════════════════════
DONNÉES DU JEU — gamedata.js
════════════════════════════════════════

gamedata.js est chargé UNE SEULE FOIS par index.html avant toute page.
Il expose ces variables globales accessibles depuis n'importe quel fragment :

  GD_EFFECTS        → Array — 100 effets  {id, nom, r, req, tags, desc, cd}
  GD_TRIGGERS       → Array — 88 déclencheurs  {nom, type, r, loc, tags, cond, desc}
  GD_FAVEURS        → Array — 28 faveurs  {id, nom, cout, effet, cond}
  GD_MALEDICTIONS   → Array — 26 malédictions  {id, nom, effet, contrepartie, cout, cond}
  GD_RELIQUES       → Array — 53 reliques  {id, nom, type, desc, bonus, malus, tags}
  GD_TAGS           → Array — 70 tags  {nom, famille, niveau, type, desc}
  GD_ARCHETYPES     → Array — 15 archétypes de synergies  {id, nom, e, tags}
  GD_CLASSES        → Object — 12 classes  {nom: {b1, b2, tags[]}}
  LOC_COMPAT        → Object — table de compatibilité ciblage {loc: [req...]}

Fonctions utilitaires disponibles :
  getCompatEffects(trigger)   → effets compatibles avec un trigger (filtre loc/req)
  getCompatTriggers(effect)   → triggers compatibles avec un effet
  getRarityOrder(r)           → 0–3 (Commun→Légendaire)
  rarityColor(r)              → couleur CSS par rareté
  detectSynergies(allTags)    → [{a: archetype, tier: 1|2|3}] triés par tier

RÈGLES D'UTILISATION :
  ✓ Accéder directement : GD_EFFECTS.filter(...), getCompatEffects(trig)
  ✓ Vérifier si besoin : if (typeof GD_CLASSES !== 'undefined')
  ✗ Ne jamais charger gamedata.js depuis une page — il est déjà là
  ✗ Ne jamais redéclarer GD_EFFECTS, GD_TRIGGERS, etc.
  ✗ Ne jamais embarquer des données du jeu dans une page

<!--
  RÈGLES CRITIQUES POUR LE JAVASCRIPT :

  1. IIFE OBLIGATOIRE — tout le JS dans (function() { 'use strict'; ... })()
     Le scope global est partagé entre toutes les pages.

  2. PRÉFIXER toutes les variables et fonctions locales (ex: "mo_").

  3. EXPOSER via window.* uniquement les fonctions appelées depuis le HTML
     (onclick, onchange, etc.). Ces assignations doivent être dans l'IIFE.

  4. document.getElementById() uniquement — pas de querySelector globaux.

  5. Les variables GD_* sont TOUJOURS disponibles à l'exécution.
     Accéder directement, sans vérification ni attente.

  6. window.registerSearchEntries() en dernier.

  7. Appeler init() à la fin de l'IIFE.
-->
<script>
(function() {
  'use strict';

  function g(id) { return document.getElementById(id); }

  // Données du jeu disponibles directement (chargées par index.html) :
  // GD_EFFECTS, GD_TRIGGERS, GD_FAVEURS, GD_MALEDICTIONS,
  // GD_RELIQUES, GD_TAGS, GD_ARCHETYPES, GD_CLASSES, LOC_COMPAT
  // getCompatEffects(), getCompatTriggers(), rarityColor(), detectSynergies()

  // --- Fonctions internes ---
  function moRenderSomething() { ... }

  // --- Fonctions exposées (appelées via onclick dans le HTML) ---
  window.moDoSomething = function(param) { ... };

  // --- Recherche ---
  if (typeof window.registerSearchEntries === 'function') {
    window.registerSearchEntries([
      { title: 'Mon Outil', page: 'mon-outil', section: 'Outils', content: 'mots-clés' },
    ]);
  }

  // --- Init ---
  function init() { moRenderSomething(); }
  init();
})();
</script>
